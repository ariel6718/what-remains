# What Remains

브라우저에서 `index.html`을 여세요. 사진, 3D 모델, 실행 코드가 파일 안에 들어 있습니다.

- 왼쪽 조각을 실크 위로 끌어다 놓습니다.
- 조각은 39개이며 같은 조각은 한 번만 씁니다. P38·P39는 잘린 가장자리만 조금 복원했습니다.
- 기본 조각 크기는 한 장 약 9×6cm입니다.
- 돌출 기본값은 6mm입니다.
- **링크 복사**하면 지금 배치가 주소에 저장됩니다. 그 주소를 열면 같은 배치가 나옵니다.

## 표현의 한계

조각의 사진과 수동으로 추적한 윤곽을 사용합니다. 두께·표면 요철은 시각화 근사치이며 실제 3D 스캔이 아닙니다. 조각의 실측 크기는 미확정입니다. 체형 비율 조절은 의상 제작용 실측 패턴을 의미하지 않으며, 실크의 물리적 드레이핑·봉제·충돌 계산은 포함하지 않습니다.

## 모델 출처

여성 인체는 Blender Studio Human Base Meshes v1.4.1의 **Body Female — Realistic** (Dan Ulrich)입니다. 공식 배포는 CC0입니다. Blender 4.5에서 불러와 크기를 정규화하고 마네킹 재질을 적용했습니다.

- https://www.blender.org/download/demo-files/#assets
- https://download.blender.org/demo/asset-bundles/human-base-meshes/

Three.js 및 three-mesh-bvh는 MIT 라이선스이며 실행 코드에 라이선스 고지가 포함됩니다. 사용자의 조각 사진에는 이 모델 라이선스가 적용되지 않습니다.

Sites에는 게시하지 않았습니다.
